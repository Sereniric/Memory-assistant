1. Never push directly to main.
2. One feature = one branch.
3. Pull main before creating a new branch.
4. Test before committing.
5. Use meaningful commit messages.
6. Open a Pull Request before merging.
7. At least one teammate reviews the PR.
8. Never commit venv/.
9. Never commit .env or secrets.
10. Don't merge AI-generated code without understanding it.
