## 🌉 What is ManasSetu?

</div>

**ManasSetu** is a web-based cognitive wellness platform designed to make cognitive activities more **accessible, engaging, and easy to understand**.

Instead of presenting cognitive activities as conventional tests, ManasSetu uses **simple game-based interactions** to engage users in activities involving memory, recall, attention, and sequence processing.

> 🎯 **Our goal:** Make cognitive assessment and awareness more approachable through an intuitive interface, gamification, and regional-language accessibility.

## 🎮 Games

</div>

### 🛒 Shopping Memory

A memory-based game where users are shown a collection of shopping items and are challenged to remember and recall them.

**Cognitive focus:**
`Memory` · `Recall` · `Concentration`

---

### 🔢 Sequence Recall

A game designed to challenge the user's ability to remember and reproduce a sequence.

**Cognitive focus:**
`Working Memory` · `Sequence Processing` · `Attention`

## 🚀 Setup

### 1️⃣ Clone the repository

```bash
git clone <your-repository-url>
```

### 2️⃣ Enter the project

```bash
cd ManasSetu
```

### 3️⃣ Create a virtual environment

```bash
python -m venv venv
```

### 4️⃣ Activate the environment

**Windows**

```bash
venv\Scripts\activate
```

**macOS / Linux**

```bash
source venv/bin/activate
```

### 5️⃣ Install dependencies

```bash
pip install -r requirements.txt
```

### 6️⃣ Run the application

```bash
python run.py
```

Open the local Flask URL shown in the terminal.

## 🌱 Development Philosophy

ManasSetu is being developed with an **MVP-first approach**.

The priority is to build a system that is:

```text
Simple
   ↓
Understandable
   ↓
Functional
   ↓
Demonstrable
   ↓
Scalable
```

Rather than trying to build every feature at once, the project focuses first on creating a working core platform and then expanding it.
